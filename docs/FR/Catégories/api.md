# API
- [GifStuffAPI](https://gifstuffapi.com/) - API pour créer des GIFs à partir d'une image
- [IP-API](https://ip-api.com/) - API de Géolocalisation
- [API Vault](https://apivault.dev/) - Collection d'APIs publiques
- [Icons8](https://img.icons8.com/) - API de recherche d'icon
- [AbuseIPDB](https://docs.abuseipdb.com/) - API de blacklist d'IPs (permet de check si une IP a été report auparavant)
- [NASA's API](https://api.nasa.gov/) - API d'images de la NASA
- [LibreTranslate](https://libretranslate.com/docs/) - API de traduction de texte ou de fichier
- [APIS.GURU](https://apis.guru/) - Collection d'APIs publiques
- [MusicBrainz](https://musicbrainz.org/doc/Developer_Resources/) - API de métadonnées de musiques
- [VocaDB](https://vocadb.net/swagger/index.html/) - API d'info musicale (Vocaloid) / [Docs](https://wiki.vocadb.net/docs/api-and-embeds/)
- [Nekosia](https://nekosia.cat/) - API d'images tirées d'animés organisés par tags / [NodeJS](https://www.npmjs.com/package/nekosia.js/)
- [Sightengine](https://sightengine.com/) - API de modération d'image
- [The Acronym Server](https://acronyms.silmaril.ie/#api) - API pour obtenir la signification d'une abbréviation/d'un acronyme
- [Datagouv](https://www.data.gouv.fr) - API des données de la France
